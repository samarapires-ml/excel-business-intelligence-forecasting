# Excel Business Intelligence & Forecasting Platform

## Overview

An end-to-end business intelligence and analytics project built in Microsoft Excel.

The project simulates a real-world business analytics engagement, transforming raw business data into actionable insights through data cleaning, data modeling, advanced Excel analysis, forecasting, scenario modeling, optimization, and executive dashboards.

## Objectives

- Build a professional Excel data analytics workflow
- Learn advanced Excel from fundamentals through expert-level features
- Develop data cleaning and transformation pipelines using Power Query
- Build relational data models using Power Pivot
- Use DAX for business intelligence calculations
- Perform customer, product, marketing, and operational analysis
- Develop forecasting models
- Perform scenario and sensitivity analysis
- Optimize business decisions using Excel Solver
- Build an interactive executive dashboard

## Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- DAX
- Advanced Excel formulas
- PivotTables & PivotCharts
- Excel Solver
- Forecasting & statistical analysis

## Business Questions

The final system will answer questions including:

- How is the business performing?
- Which customers and products drive profitability?
- Which regions and channels perform best?
- Which customers are at risk?
- What will revenue look like over the next 12 months?
- How should the marketing budget be allocated?
- What happens under different business scenarios?
- What strategic actions should management take?
